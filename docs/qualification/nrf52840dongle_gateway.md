# Qualification report: nRF52840 Dongle gateway (`nrf52840dongle_gateway`)

Status: **buildable** ([status definitions](../hardware/matrix.md))

> The gateway application (`apps/gateway`, [gateway-firmware.md](../gateway-firmware.md))
> links within this board's exact memory geometry behind Nordic's factory USB
> bootloader (code at `0x1000`, settings at `0xd8000`), passes
> `tools/verify_stack.py` and meets the flash headroom target (no RAM target is
> set). Its configuration is the DK gateway's ([nrf52840_gateway](nrf52840_gateway.md))
> without the DK's QSPI flash driver, so that board's native_sim results apply;
> nothing has run on a dongle yet. Flashing: [building.md](../building.md#flashing-the-nrf52840-dongle-usb-bootloader).
